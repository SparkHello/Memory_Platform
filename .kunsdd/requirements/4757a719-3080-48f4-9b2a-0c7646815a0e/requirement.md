# Web Console 首次使用体验优化

## 背景

基于 2026-08-16 对本地 Docker 部署（127.0.0.1:2026）的实测：用真实 console token 走遍了全部 15 个页面（含无 key 首启页）。当前是一台刚装好、数据库为空的新机器，这正是新用户看到的第一眼。实测发现以下体验问题：

**P0 — 三种密钥反复要求用户分辨，配置链路割裂**

- 首启页、连接设置页、模型与路由页、工作室页都在用大段文案解释「gateway.txt 是 Console token、admin.txt 管模型、chat token 管聊天，别填混」。文案本身说明设计容易填错。
- 首次配模型要在「工作室看到提示 → 去文件系统找 admin.txt → 到模型与路由页粘贴 → 加渠道选模型 → 回工作室生成 chat token」之间来回跳，且 admin key 「只保留到本页关闭」，中途离开就要重贴。
- 首启必须自己用文本编辑器打开 `credentials/gateway.txt` 复制 64 位 token；`memgw open` 只打开页面，不带任何免复制登录手段。

**P1 — 空库状态下 15 个页面几乎都是空态，用户不知道下一步**

- 实测新装机器上：记忆库、核心记忆、对话上下文、知识库、检索调试、体检、评测、召回、用量、日志全部只有空态卡片。只有工作室页有「完成首次配置」引导。
- 简洁模式导航仍露出 6 个入口，专家模式 15 个；空数据时这些入口点进去没有可做的事，也没有跨页的统一「还差哪一步」。

**P1 — 未初始化的功能被渲染成错误**

- 评测页未初始化快照时，`GET /memories/evaluation/recall/workbench` 返回 404（后端对 FileNotFoundError 的预期行为），页面却同时显示错误条「请求的内容不存在 / 重试」和空态引导「尚未初始化召回评测快照」，自相矛盾。

**P2 — 界面噪音与术语密度**

- 「服务在线 · 待配置模型」横幅出现在全部 15 个页面顶部，不可消除。
- 工作室页直接罗列 7 个未就绪用途路由原始 ID（memory.chat、memory.extract…）；检索调试、对话上下文等页充斥「逐字片段 / 稳定引用 / 自动分支 / 分叉点」等内部术语，非专家用户难以理解。
- 简洁 / 专家两套导航分组完全不同（开始·内容·使用 vs 工作室·记忆·知识·治理·数据·系统），切换模式等于重学一遍信息架构。

做得好的地方（保留）：首启两步向导结构、凭证用途区分文案、admin key 不落地浏览器、只读 token、私密记忆遮罩视图。

## 目标

1. 新用户从「打开控制台」到「能聊天」的密钥操作收敛为一条不回头的主线：登录 → 验证 admin → 加渠道选模型 → 生成 chat token，中途不因跳转或离开页面而重贴密钥。
2. 降低首启找 key 门槛：提供至少一种免手动复制 64 位 token 的登录方式（如 `memgw open` 生成一次性登录链接，或本机回环首次引导流程），同时不降低 token 鉴权强度。
3. 空库状态下，所有页面把用户引向「下一步该做什么」，而不是只展示空卡片；工作室引导进度与各页联动。
4. 「未初始化 / 无数据」与「出错」在界面上严格区分：预期空态不显示错误条、不出 404 请求噪音。
5. 面向普通用户隐藏内部术语（路由原始 ID、检索机制名词），专家模式下保留。

## 验收标准

- 全新安装后，仅通过浏览器即可完成从登录到生成 chat token 的全流程，无需手动用文本编辑器打开凭据文件；如保留文件方式，页面上必须能一键复制或直达。
- admin key 验证一次后，在完成渠道配置前不因页面切换而失效（会话内保持，关闭浏览器后可失效）。
- 空库时随机抽查 5 个页面（记忆库、知识库、体检、用量、日志），每页都有指向当前下一步操作的明确引导，而非孤立空态。
- 评测页未初始化快照时不出现错误提示条，也不产生 4xx 请求；初始化入口就是页面主操作。
- 「待配置模型」类全局横幅只在相关页面出现一次且可关闭，关闭状态跨页面保持。
- 简洁模式下任何页面不出现 `memory.chat` 等原始路由 ID 和「deployment / 逐字片段 / 分叉点」类内部术语；由 e2e（playwright）断言。
- 以上不破坏现有凭证安全模型：token 不明文入日志 / URL 持久参数 / 浏览器长期存储（登录会话除外）。

## 实测记录（2026-08-16）

- 环境：Docker 栈 `memory-platform-*`，Console 于 `http://127.0.0.1:2026/ui/`，真实 gateway.txt token，headless Chromium 1440×900 遍历 15 页 + 无 key 首启页。
- 除评测页 404 外无其他请求失败或前端异常；各页 DOMContentLoaded+1.8s 内渲染完成。
- 截图与页面文本存档于 /tmp/cua/pages/（临时目录，重启后失效）。
