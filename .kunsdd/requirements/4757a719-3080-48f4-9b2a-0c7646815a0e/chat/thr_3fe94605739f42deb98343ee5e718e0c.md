1. **P0 三密钥模型是最大体验负担** — gateway.txt（登录网页）、admin.txt（配模型）、chat/mcp token（客户端）四种凭证，首启页/设置页/模型页/工作室页都在用大段文案解释"别填混"——文案本身就证明设计容易错。且 admin key "只保留到本页关闭"，配模型中途切页就要重贴；首启还得自己用文本编辑器翻 `credentials/gateway.txt` 复制 64 位 token。

**安全设计要点**
- `POST /auth/console-login-code`：走既有 `_role_for_path`（`/auth` 前缀 → console role），mint 时换发一个新的 console role token，code 为 `mgc_` + 192 bit 随机；AUTH DB 只存 `sha256(code)`（复用 `tokens.py` 的 `_hash_secret`）、绑定的 16 位 token id、过期/使用状态；TTL 300 秒。

- **一次性登录链接**（最大项）：新增后端 `POST /auth/console-login-code`（需 console token，code 只存 sha256、5 分钟、单次使用、fail-closed）与 `POST /auth/console-login-exchange`（免 Bearer 但仅本机来源——回环/RFC1918 + localhost Host，复用既有速率限制；失败统一 401 无信息泄漏）。`memgw open` 与 Docker 双安装器（sh/ps1）现在直接打印/打开 `…/ui/#login=<code>`，浏览器端识别 code、交换写入 token、立即抹掉 URL 中的 code。新用户**不再需要手动复制 64 位 token**；手动粘贴 gateway.txt 兜底保留。
- **admin key 会话保持**：验证成功后存 sessionStorage（关标签页即失效、不写 localStorage），同标签页内切换页面不再重贴；挂载时静默重验，密钥轮换则安全回落；新增「忘记管理密钥」按钮。向导完成态新增「生成 chat token」CTA 直达 `#/integration`，消除了回工作室的折返。

**P1 — 空库引导与假错误**
- **评测页**：diagnosis 响应新增 `snapshot_initialized`，未初始化时不再发起 workbench 请求（消除 404 网络噪音）也不显示错误条，直接渲染「初始化快照」空态。
- **空态下一步引导**：新增 `nextStep.ts` + `NextStepHint`，记忆库/知识库/体检/用量/日志 5 页在模型未就绪时显示「去配置模型渠道 / 去修复模型网关配置」引导。

**P2 — 噪音与术语**
- **横幅收敛**：warning 横幅只在工作室/模型/设置/接入 4 页出现，可关闭（写入 `dismissedStatus`，消息变化才复现），bad 不受限不可关。
- **简洁模式术语**：Dashboard 不再罗列 `memory.chat` 原始路由 ID（改为「N 项用途尚未就绪」）；「逐字片段→原文片段」「稳定引用→引用位置」「分叉点→分支点」；简洁页脚去除 deployment 字样。专家模式保留原词。
