# Plan: 缓存命中价格 + 路由定价简化 + 记忆体检按钮

## Summary
Three related changes:
1. **Add `cache_hit_price_per_million`** to ProviderModelConfig (flat + tiered), wired through backend → API → frontend → TOML.
2. **Remove pricing fields from RouteConfig**; billing now looks up the linked ProviderModelConfig via `provider_model_id`.
3. **Add action button to `review` cards** on ReviewPage: click extends `review_after` by 15 days.

### Step 4: Backend — `billing.py` use ProviderModelConfig pricing

**File:** `app/providers/billing.py`
- Import `ProviderModelConfig`, `json`.
- Change `build_success_usage_event` signature: add `model: ProviderModelConfig` parameter.
- Read `input_price_per_million`, `output_price_per_million`, `cache_hit_price_per_million`, `currency` from `model` instead of `route`.
- For `input_cost`: `(prompt_tokens / 1M) * model.input_price_per_million`. Cache hit token count not yet available from upstream response, so defer full cache-hit billing until `usage.prompt_cache_hit_tokens` is standard. For now: add `cache_hit_tokens` parameter defaulting to 0, compute `input_cost = ((prompt_tokens - cache_hit_tokens) / 1M) * model.input_price_per_million + (cache_hit_tokens / 1M) * model.cache_hit_price_per_million`.
- Change `build_error_usage_event` signature: add `model: ProviderModelConfig`, read `currency` from it.
- Add `_resolve_pricing(model, prompt_tokens)` helper: if `pricing_mode == "tiered"`, parse `pricing_tiers_json` and find the tier matching `prompt_tokens`; else use flat prices.

**File:** `app/providers/client.py`
- In `_record_success` and `_record_error`: look up `ProviderModelConfig` via `self.config.provider_models.get(selection.route.provider_model_id)`. If not found, log warning and skip billing. Pass model to billing functions.
- Parse `usage.prompt_cache_hit_tokens` from response if present, pass to billing.

(covers: 缓存命中价格, 路由移除独立定价)

## Risks
| Risk | Mitigation |
|------|-----------|
| Cache hit price defaults to 0; existing billing unchanged | Default 0 means no cost delta for existing configs |
| Tier JSON `cache_hit` may be null/missing from old data | `priceTierDraftsFromJson` defaults to `"0"` |
| Old routes without `provider_model_id` stop billing | User confirmed: delete and reconfigure |
| Tiered pricing in billing not fully implemented | For now flat model prices used even for tiered models; tiered billing deferred to follow-up |
| TypeScript build must pass | Step 11 verifies |
